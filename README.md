# Alias — игра в объяснение слов

Командная игра «объясни слово, не называя его». Работает полностью офлайн, без сервера: словарь зашит в сборку
и обновляется вместе с версией приложения.

- **5 800+ русских слов** в трёх уровнях сложности и 28 тематических категориях
- **Слова не повторяются**: приложение запоминает, что вам уже выпадало, и не показывает это снова, пока вы не увидите весь уровень
- Свайп вверх — угадали, вниз — пропуск (или большие кнопки)
- Настройки: сложность (лёгкий / средний / сложный / микс), время раунда, очки до победы, штраф за пропуск, «последнее слово для всех»
- 2–6 команд, необязательные имена игроков: приложение подсказывает, кто объясняет, и меняет объясняющего по кругу
- Проверка после хода: можно исправить случайные свайпы
- Честная победа: круг всегда доигрывается до конца, при ничьей играется дополнительный круг
- Партия сохраняется: можно свернуть или закрыть приложение и продолжить с того же места (идущий раунд встаёт на паузу)
- Звуки синтезируются на лету, есть вибрация, экран не гаснет во время партии
- Тёмная тема, веб-фронт на React, мобильные сборки через Capacitor

## Стек

React 19 · TypeScript · Vite · Tailwind CSS 4 · Zustand · Motion · Capacitor 8 · Vitest

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173 — удобнее всего в мобильном режиме DevTools
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер |
| `npm run build` | проверка типов и продакшен-сборка в `dist/` |
| `npm test` | юнит-тесты (движок игры, колода, словарь, стор) |
| `npm run typecheck` | только проверка типов |
| `npm run words:build` | пересобрать словарь из `words/ru/*.txt` |
| `npm run words:check` | проверить, что собранный словарь совпадает с исходниками |

## Мобильные приложения (Capacitor)

Нативные проекты не лежат в репозитории, их генерирует Capacitor. Один раз:

```bash
npm run build
npx cap add ios        # нужен macOS + Xcode
npx cap add android    # нужен Android Studio
```

Иконка и сплэш генерируются из `resources/icon.png` (1024×1024) и `resources/splash.png` (2732×2732):

```bash
npx @capacitor/assets generate --iconBackgroundColor '#07090a' --splashBackgroundColor '#07090a'
```

Дальше после каждого изменения веб-части:

```bash
npm run cap:ios        # сборка + sync + открыть Xcode
npm run cap:android    # сборка + sync + открыть Android Studio
```

Перед публикацией поменяйте `appId` и `appName` в `capacitor.config.ts`.

Используемые плагины: `@capacitor/haptics` (вибрация), `@capacitor/preferences` (надёжное хранилище вместо
localStorage в WebView), `@capacitor/status-bar`, `@capacitor/splash-screen`, `@capacitor/app` (кнопка «Назад»
на Android, пауза при сворачивании), `@capacitor-community/keep-awake` (экран не гаснет).

## Словарь

Исходники словаря лежат в `words/ru/`: по одному файлу на категорию, одно слово на строку, три секции:

```
# 🐾 Животные

[easy]
кошка
собака

[medium]
кальмар

[hard]
утконос
```

`npm run words:build` проверяет словарь и собирает `src/data/words.ru.json`:

- только строчная кириллица, пробел или дефис, не больше трёх слов во фразе;
- без дублей по всему словарю (ё и е считаются одной буквой);
- ошибки выводятся с именем файла и номером строки.

Как выбирать уровень:

- **easy**: конкретные бытовые вещи, которые знает ребёнок 7–10 лет (кошка, мяч, дождь);
- **medium**: знакомо любому взрослому, но менее бытово или требует подумать (телескоп, ипотека, кальмар);
- **hard**: абстракции, термины, редкие слова и устойчивые выражения, которые образованный взрослый всё же знает
  (ностальгия, парадокс, эффект плацебо).

Чтобы выпустить обновление словаря, добавьте слова, увеличьте `version` в `words/ru/meta.json`, выполните
`npm run words:build` и соберите новую версию приложения. История просмотренных слов хранится по самим словам,
поэтому новые слова у игроков сразу окажутся «непросмотренными».

## Структура

```
src/
  game/        чистая логика: типы, подсчёт очков, очерёдность, победа, колода без повторов
  store/       Zustand-сторы: партия (с сохранением), настройки, UI, история просмотренных слов
  data/        собранный словарь и его загрузка
  screens/     экраны: главный, настройка команд и правил, правила, настройки
  screens/game/ экраны партии: заставка хода, раунд, итоги хода, счёт, победа
  components/  UI-кит: кнопки, переключатели, карточки, диалог, тосты, конфетти
  lib/         звуки, вибрация, нативные обёртки Capacitor, форматирование
words/ru/      исходники словаря
scripts/       сборка словаря
resources/     исходники иконки и сплэша для нативных сборок
```

Логика партии разделена на две части: чистые функции в `src/game/engine.ts`, покрытые тестами, и стор
`src/store/gameStore.ts` — машина состояний хода (`ready → countdown → running ⇄ paused → lastword → review`).
Какой экран партии показать, определяется только состоянием стора, поэтому восстановление после перезапуска
работает само.

## Что дальше

На главном экране уже есть заглушки режимов, под них заложена структура данных: у каждого слова есть категория.

- **Темы**: игра только выбранными категориями
- **Крокодил**: показывать слово жестами
- **Шляпа**: каждый игрок добавляет свои слова
- Дополнительные наборы слов (18+, детский, английский)
